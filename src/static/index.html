REFERENCE / 01

MCP Reference

Strict read-only tools, browsable schema resources, and diagnostic prompts.

Strict Read-Only Defense in Depth

Three independent layers; any one of them blocks writes.
01 / AST Parser Layer

Queries parsed via sqlglot. Rejects any mutation (INSERT, UPDATE, DELETE, DROP, ALTER, TRUNCATE, MERGE, write CTEs, procedures) before reaching the database.

02 / Engine Session Layer

PostgreSQL sessions enforce SET default_transaction_read_only = on and execute inside explicit read-only transactions at the engine level.

03 / Statement Timeout Guard

Configurable statement_timeout_ms (default: 30s) prevents runaway queries from locking database connections.

MCP Resources

URI templates for inspection without tool execution.
  • postgres://profiles
    Stored connection profiles and active status.
  • postgres://schemas
    User schemas in the active database.
  • postgres://schemas/{schema}/tables
    Tables and views within the specified schema.
  • postgres://schemas/{schema}/tables/{table}
    Column types, nullability, and primary keys.

MCP Guided Prompts

Multi-step diagnostic prompt workflows.
  • debug_slow_query(query)
    Runs EXPLAIN ANALYZE, checks indexes, and suggests plan fixes.
  • explore_table(table, schema)
    Surfaces schema, constraints, statistics, and sample rows.
  • find_data_issues(table, schema)
    Checks for NULL spikes, duplicates, and broken foreign keys.
