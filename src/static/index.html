MCP Reference

Strict read-only tools, browsable schema resources, and diagnostic prompts.

Strict Read-Only Defense in Depth
01 / AST Parser Layer

Queries parsed via sqlglot. Rejects any mutation (INSERT, UPDATE, DELETE, DROP, ALTER, TRUNCATE, MERGE, write CTEs, procedures) before reaching the database.

02 / Engine Session Layer

PostgreSQL sessions enforce SET default_transaction_read_only = on and execute inside explicit read-only transactions at the engine level.

03 / Statement Timeout Guard

Configurable statement_timeout_ms (default: 30s) prevents runaway queries from locking database connections.
